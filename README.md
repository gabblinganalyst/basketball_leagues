## Introduction

A curated directory of professional men's basketball leagues in the continent of Australia, and East Asia.

This directory is limited to metadata. Each piece of information was verified by a person-in-the-loop. Despite this verification of metadata, the information on record may need to be updated over time, and for more details please take a look at the Appendix's [List of Reasons for Stale URLs](#list-of-reasons-for-stale-urls). In addition, the directory is expected to grow over time based on the following dimensions:
1. The number of leagues covered
2. The number of languages supported
3. The number of teams covered
4. The type of metadata covered

### List of N/A Value Types

- **No landing webpage**: The league website does not have a landing webpage to show a directory of the league's teams or players.
- **No account**: The league does not operate an official account on this platform.

### List of Reasons for Stale URLs

A URL may become stale in this repository due to the following reasons:
1. The webpage URL address was changed
2. The account name was changed (and as a result, the webpage URL address was changed)
3. The webpage is no longer hosted
4. The website is no longer hosted
5. The account was deactivated
